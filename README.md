# Godot-Fighting-Game
A fully playable 2D fighting game developed over the summer using Godot and GDScript. Features include directional movement, hit detection, blocking, projectile attacks, custom animations, and SFX. Built as a two‑player local fighting game with a complete death

How to Play: 
Download and extract the ZIP file, then launch the executable. Controls are shown in‑game.
